# ZoneLinks Builder — плагин для Figma

Плагин достраивает Figma-файл сайта прямо у тебя в Figma: переводит его на ZoneLinks (название, морские цвета, новый знак), строит 4 экрана сайта, оформляет UI-кит и страницу логотипа и иконок, а заодно убирает градиенты.

Он работает через обычный Plugin API, а не через коннектор Claude. Поэтому **нет лимитов вызовов и ничего не нужно покупать**: хватает бесплатного тарифа Figma Starter. В интернет плагин не ходит (`networkAccess: none`) и никуда ничего не отправляет.

## Как запустить (один раз — 2 минуты)

1. Установи **десктопное приложение Figma** (бесплатно, figma.com/downloads). Плагины «в разработке» запускаются только в нём, не в браузере.
2. Открой в нём Figma-файл проекта (он пока называется **Amberite** — переименовать в ZoneLinks можно двойным щелчком по названию вверху; плагин сам этого сделать не может).
3. Меню → **Plugins → Development → Import plugin from manifest…**
   (в русском интерфейсе: **Плагины → Разработка → Импортировать плагин из манифеста…**)
   и выбери файл `figma-plugin/manifest.json` из этой папки.
   Если раньше уже импортировал «Amberite Builder» — удали его из списка и импортируй заново.
4. Меню → **Plugins → Development → ZoneLinks Builder**.
5. Оставь нужные галочки и нажми **«Запустить»**. Обычно это занимает 10–30 секунд, ход работы виден в журнале.

## Что делает каждый шаг

| Шаг | Результат |
|---|---|
| Ребрендинг | Переменные «Тема» — морская палитра (как в `style.css`), «teal» → «green»; в логотипе название ZoneLinks; знак пересобран (сфера из волн + «плюс» снизу); все привязанные цвета обновлены |
| Убрать градиенты | Кнопки, кнопка скачивания и иконки проектов — сплошные цвета |
| 1 · Макет сайта | Страница «1 · Макет сайта»: Главная, Каталог модов, Страница мода, Окно скачивания (1440px) |
| 2 · UI-кит | Страница «2 · UI-кит»: палитры тёмной и светлой темы, типографика, тени и все компоненты по разделам |
| 3 · Логотип и иконки | Страница «3 · Логотип и иконки»: варианты знака, логотип с названием, размеры, иконки с подписями, мастер-компоненты |

Запускать можно сколько угодно раз: каждый шаг сначала удаляет свой прошлый результат (компоненты при этом не пропадают и связи с экземплярами не рвутся).

## Если что-то пошло не так

- **«нет переменной …» / «нет компонента …»** — плагин запущен не в том файле. Он работает только в Figma-файле проекта.
- **Шрифт не найден** — нужен Manrope (есть в Figma по умолчанию). Если Figma предлагает установить шрифты — согласись.
- Любая другая ошибка видна в журнале плагина. Скопируй её текст и пришли мне — поправлю код.
